Privacy

Windows build maintained by John Paul · Updated October 12, 2026

Mimo has no account, advertising or analytics. The app communicates with services you choose to connect, using your own accounts and credentials.

Data on your computer

DataLocation
API keys and service tokensWindows Credential Manager, under com.johnpaul.mimo
Preferences%APPDATA%\Mimo\settings.json
Dropped-file copies and local app data%LOCALAPPDATA%\Mimo
Diagnostic log%LOCALAPPDATA%\Mimo\mimo.log, capped at approximately 1 MB

Services you connect

Chat messages and prepared attachments are sent to the chat provider you select when you submit them. Connected services process requests under their own policies. Local Ollama uses the local service you configure.

Coding hooks pass session events to Mimo over a local, authenticated named pipe. Before changing a coding tool's settings, the hook installer previews the changes and saves a dated backup.

Remove data

Remove credentials and coding hooks in Settings, then uninstall Mimo. You can delete its preferences and local-data folders to clear the remaining local files. This documentation website uses no analytics or cookies.

Confidentialité

Mimo n'a ni compte, ni publicité, ni statistiques. Les clés restent dans le Gestionnaire d'identification Windows, sous com.johnpaul.mimo. Les préférences sont dans %APPDATA%\Mimo et les données locales dans %LOCALAPPDATA%\Mimo.

Les messages et fichiers préparés sont envoyés au fournisseur du chat choisi quand tu les soumets. Les hooks transmettent les événements des agents par une connexion locale authentifiée. Leur installation affiche les modifications et sauvegarde les réglages.

Retire les clés et les hooks dans les Réglages, puis désinstalle Mimo. Tu peux ensuite supprimer ses dossiers locaux. Cette version Windows et son installation sont maintenues par John Paul.
