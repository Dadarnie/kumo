Mimo support

Install or run Mimo

Use the Windows build guide. The installer and portable app use the Mimo name; the Windows build is maintained by John Paul.

Connect your tools

Open Settings → Connections to configure coding hooks, chat provider credentials and optional services. Hook installation previews changes and creates a dated backup. Chat has its own provider and model picker.

Use files and media

Drop a file onto Mimo, then choose Ask a question or Cancel. The Media tab follows supported Windows media sessions and offers the controls reported by the active player.

Report a problem

Include the Mimo version, your Windows version and steps to reproduce it. The local diagnostic log is %LOCALAPPDATA%\Mimo\mimo.log. Review its contents before sharing it.

Uninstall

Remove coding hooks through Settings → Connections, then use Windows Settings → Apps → Mimo → Uninstall. Preferences are under %APPDATA%\Mimo and local data under %LOCALAPPDATA%\Mimo. Stored credentials can be removed in Settings.

Assistance Mimo

Consulte le guide de compilation Windows pour créer l'installeur. John Paul maintient cette version Windows et son installation.

Réglages → Connexions permet de configurer les hooks des agents, les clés du chat et les services. L'installation des hooks affiche les modifications et crée une sauvegarde datée.

Pour un problème, indique la version de Mimo, ta version de Windows et les étapes pour le reproduire. Le journal local se trouve dans %LOCALAPPDATA%\Mimo\mimo.log.

Retire les hooks depuis les Réglages, puis désinstalle Mimo dans Paramètres Windows → Applications. Les préférences se trouvent dans %APPDATA%\Mimo et les données locales dans %LOCALAPPDATA%\Mimo.
