# Agent artwork

These local icons identify Mimo's supported coding tools. Vendor names and
trademarks belong to their respective owners. The neutral cards around the
icons are README presentation; they do not imply endorsement.

[sources.json](sources.json) records the original download URL, source hash and
rendered badge hash. Source artwork is kept in `marks/` without recoloring.

- Claude Code: [Claude](https://claude.com/).
- Codex: the OpenAI mark from [OpenAI's documentation](https://learn.chatgpt.com/docs).
- Cursor: [official brand resources](https://cursor.com/brand).
- Gemini CLI: [official project site](https://geminicli.com/).
- Antigravity: [official press assets](https://antigravity.google/press).
- Muse Code: the Meta developer-site mark from [Meta](https://dev.meta.ai/).
- OpenCode: [official brand resources](https://opencode.ai/brand).
- Copilot CLI: [GitHub Primer Octicons](https://github.com/primer/octicons), MIT;
  [copyright and permission notice](../../../windows/src/mimo/brands/README.md).
- Hermes Agent: [Nous Research's official site](https://hermes-agent.nousresearch.com/).

The marks keep their vendor terms. Mimo's asset restrictions do not apply to
these third-party marks. Rebuild the cards with
`node scripts/render-agent-badges.mjs`.
