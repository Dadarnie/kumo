Build Mimo for Windows

Build and installation by John Paul · Windows 10/11

The application source and Rust workspace live in \windows inside your Mimo project folder. You need Node 20+, Rust, MSVC C++ build tools and WebView2.

Download

Download Mimo-Windows-setup.exe · SHA-256 checksum. The installer is not code-signed. Windows may warn about an unknown publisher. Review the source, build it yourself or compare the downloaded file with the release checksum. A checksum confirms file identity, not safety.

Create the installer

cd C:\projects\Mimo\windows
npm ci
npm run pack

The installer is copied to windows\release\Mimo-Windows-setup.exe and windows\release\Mimo-Windows-<version>-setup.exe. Run either installer to install Mimo for your Windows account.

Run from source

cd C:\projects\Mimo\windows
npm run tauri dev

The local project includes README.md, windows\README.md and the complete source tree. Source and Windows downloads are available in the Mimo repository.
