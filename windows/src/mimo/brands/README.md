# Integration badge artwork

These local vectors identify the connected application. They are separate from Mimo's own logo and character identity; no network fetch happens during rendering.

- `github.svg`: GitHub's [Primer Octicons mark-github-24](https://github.com/primer/octicons/blob/main/icons/mark-github-24.svg), MIT. Copyright GitHub, Inc. The Octicons license is included below.
- `n8n.svg`: n8n's [design-system logo icon](https://github.com/n8n-io/n8n/blob/master/packages/frontend/%40n8n/design-system/src/components/N8nLogo/logo-icon.svg). Kept in its original pink, as described in [n8n's brand guidelines](https://n8n.io/brandguidelines/).
- `vscode.svg`: unmodified blue SVG from Microsoft's [VS Code icon package](https://code.visualstudio.com/assets/branding/visual-studio-code-icons.zip). See [icon usage guidelines](https://code.visualstudio.com/brand).
- Vercel: the native vector triangle is the [Vercel brand symbol](https://vercel.com/geist/brands), kept at its original equilateral proportions.

Each authentic app icon sits inside a compact neutral circular Mimo badge, with consistent padding and a soft rim. The source artwork supplies the shape and original proportions; a locally cached alpha mask renders the mark in Mimo's current character color. The four status badges independently keep their blue, green, gray and orange fills. No vendor colors appear in the companion's app badges.
