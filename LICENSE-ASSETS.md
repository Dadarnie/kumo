# Kumo assets

Kumo's name, cloud mascot, app icon and sounds are part of this repository and are
released under the same [MIT license](LICENSE) as the code.

| Asset | Source |
| --- | --- |
| Cloud mascot | Drawn in code: `windows/src/mimo/face.ts` |
| App icon | `windows/kumo-app-icon/kumo-app-icon.svg`, exported by `windows/scripts/gen-icons.mjs` |
| Sounds | Synthesized by `windows/scripts/kumo-sounds.mjs` into `windows/assets/sounds/` |

Kumo is a fork of [Mimo](https://github.com/Jiocode1/mimo) by John Paul. Mimo's
name, mascot artwork, icons and sound recordings, which carried separate asset
terms, are not included in Kumo. Third-party marks (agent and integration logos)
keep their own terms; see [THIRD_PARTY_NOTICES](THIRD_PARTY_NOTICES).
